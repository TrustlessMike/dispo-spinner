A fun, interactive wheel spinner for cannabis dispensaries. Engage customers with gamified product discovery.

## Features

- 🎡 Interactive spin wheel animation
- 🎨 Customizable segments and colors
- 📱 Mobile-responsive design
- 🏪 Dispensary branding support
- ⚡ Vercel-ready deployment

## Quick Start

```bash
git clone https://github.com/TrustlessMike/dispo-spinner.git
cd dispo-spinner
npm install
npm run dev
```

## Customization

Edit `data/segments.ts` to customize:
- Prize names
- Colors
- Win probabilities
